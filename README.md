# 元素周期表 · 三维重建

门捷列夫元素周期表的 Three.js 三维交互重建。118 种元素真实数据，三种立体排布，
性质高度地形，1869 年历史视角，可导出 GLB 模型文件。

**公网地址：https://matrix-air.github.io/periodic-table-3d/**（GitHub Pages，2026-10-05 发布）
**姊妹页 · 45 天化学修炼场：https://matrix-air.github.io/periodic-table-3d/arena.html**（打怪升级版游戏化执行层，3D 页右上金色按钮直达，修炼场右上可返回）

## 快速开始

```bash
./start.sh            # 本地启动（默认 8930 端口）
# 打开 http://127.0.0.1:8930
```

或手动：`python3 -m http.server 8930` 后访问 `http://127.0.0.1:8930`。
全部资源本地化（three.js r160 已 vendor 进 `assets/`），离线可运行，无需构建。

## 三种三维排布

| 视图 | 形态 | 讲的是什么事 |
|------|------|--------------|
| 经典立体 | 标准 18 族排布立体化，f 区两条附加带 | 周期表本来的样子 + 性质在第三维上的起伏 |
| 周期环塔 | 每个周期一圈、自下而上堆成塔，f 区并入第 6/7 层 | 周期 = 一层环，塔越往下越宽 |
| 序数螺旋 | 按原子序数排成螺旋（每圈 16 元素，致敬 1862 钍螺旋） | 周期性本质上是原子序数的回旋 |

## 高度映射（经典立体）

第三维高度可以映射四种真实性质，周期性锯齿一目了然：

- **原子半径（共价，Cordero 2008）**：碱金属峰、稀有气体谷、镧系收缩
- **电负性（泡令）**：氟是全场最高峰
- **第一电离能**：稀有气体尖峰 vs 碱金属深谷
- **原子质量**：近似线性增长中的跳跃

## 门捷列夫 1869 视角

勾选「1869 已知视角」：建表时已确认的 62 种元素保持发亮，其余位置变成幽灵空位——
此后 157 年里被逐一填上，无一落空。**镓、钪、锗、锝、铼**五个位置带预言微光
（门捷列夫预言的类铝/类硼/类硅/类锰，点击看预言 vs 实测对比；氦有专属注脚）。

## 其他交互

- 点击任意元素：详情面板（中英文名、电子排布、电负性、半径、电离能、发现年份、物态）
- 搜索：符号 / 中文名 / 英文名 / 序数，命中高亮其余压暗
- 图例：点击分区色块隔离显示该类元素
- 自动旋转、重置视角、**导出 GLB**（可导入 Blender / 系统三维查看器）

## 数据口径（诚实声明）

- 相对原子质量：IUPAC（2021 通行值）；人工元素为最稳定同位素质量数
- 共价半径：Cordero 2008；**97 号起为预测值**，104 号起电负性缺数据以「—」示
- 第一电离能：标准手册值；**104 号起为预测值**（详情面板逐项标注）
- 1869 已知名单按「发现 ≤1869 且已入门捷列夫表」口径 = 62 种；
  氦 1868 年已见于太阳光谱但表内无位，点氦看注脚
- 立方体尺寸/高度为数据可视化映射，非真实尺度
